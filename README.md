## About the Project
A modern, high-converting WordPress one-page website designed for **Montreal Polymers Inc.**, Quebec's leading eco-friendly industrial plastic and PVC recycling company.

### Key Visual & Technical Highlights:
- **100% Chemical-Free & Zero-Solvent Facility**: Contrasting cold mechanical granulation against conventional toxic acid washes and hazardous incinerators.
- **Warm Yellowish-Green & Golden Accent Palette**: Fresh organic lime-leaf tones (`#65a30d`, `#84cc16`, `#a3e635`) paired with brand gold (`#ffcb0a`) and deep warm forest (`#142306`).
- **3D Interactive WebGL Animation**: Real-time Three.js scene featuring a rotating geodesic polymer sphere, glowing inner eco-core, and floating recycled polymer flakes.
- **Interactive Landfill & Revenue Calculator**: Real-time slider estimating annual cubic meters diverted and monthly scrap buyback payouts ($CAD).
- **Dual Conversion Funnel**: Request Material Quote (Buyers) vs. Sell Factory Scrap with Photos (Sellers).
- **Complete Responsive Design**: Fully optimized across desktop, tablet, and mobile screens.

## File Structure
- `index.html` — Production-ready standalone one-page prototype (Three.js + Tailwind CSS + Lucide Icons)

- `montreal_polymers_design.svg` — 1440 × 5600 px vector artboard (drag-and-drop directly into Figma)
- `figma_design_generator.js` — Figma console automation script to generate native Auto-Layout frames
